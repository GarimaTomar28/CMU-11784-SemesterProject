# Hallucination Detection in Speech and Audio LLMs

### Detection, Mitigation, and Beyond

A research-oriented project investigating hallucinations in Automatic Speech Recognition (ASR) systems, with a focus on detecting fluent but semantically incorrect transcripts generated by OpenAI Whisper.

---

##  Overview

Automatic Speech Recognition (ASR) systems are increasingly used in applications such as medical documentation, legal transcription, accessibility, and voice-based AI systems.

However, ASR models can sometimes produce **hallucinated transcripts** — outputs that are fluent and grammatically plausible but are not actually supported by the input audio.

Traditional metrics such as **Word Error Rate (WER)** do not reliably capture this failure mode. A transcript can appear lexically reasonable while being completely disconnected from the source audio.

This project investigates lightweight methods for detecting such hallucinations using signals already available from the ASR model, as well as language-model-based features.

---

## 🎯 Objectives

The project focuses on four primary objectives:

- **Quantify hallucination rates** across datasets with different levels of difficulty.
- **Investigate the limitations of WER** as a standalone measure of ASR reliability.
- **Evaluate confidence-based signals** from Whisper for hallucination detection.
- **Study domain-specific risks**, particularly in medical speech recognition.

---

##  Approach

The project evaluates three hallucination detection approaches built on top of Whisper:

### 1. ASR-Based Detector

Uses signals directly produced by Whisper:

- `avg_logprob`
- `no_speech_prob`
- `compression_ratio`
- WER

These features provide lightweight indicators of model uncertainty, lack of speech, and repetitive/degenerate outputs.

### 2. Language Model-Based Detector

Uses transcript-side language-model features, including:

- Language-model perplexity
- Unique token ratio
- Surprisal-based measures

The motivation is to determine whether unusual linguistic patterns can indicate hallucinated transcripts.

### 3. Hybrid Detector

Combines ASR-side confidence signals with language-model features to investigate whether combining both sources improves hallucination detection.

---

##  Model

The project uses **OpenAI Whisper**, a transformer-based encoder-decoder ASR model.

Whisper converts the input audio into log-mel spectrogram representations, processes them through an encoder, and generates the transcript autoregressively through its decoder.

We evaluate three Whisper variants:

- Whisper Tiny
- Whisper Base
- Whisper Small

All audio inputs are standardized to **16 kHz**.

---

##  Dataset

The experiments use a merged dataset containing **665 labeled utterances** from multiple sources representing different levels of acoustic and domain difficulty.

| Dataset | Description |
|---|---|
| **LibriSpeech** | Clean audiobook speech used as an in-distribution baseline |
| **Mozilla Common Voice** | Crowd-sourced speech with diverse speakers, accents, and recording conditions |
| **PriMock57** | Simulated medical consultations containing domain-specific terminology |
| **Adversarial Audio** | Custom stress-test dataset containing silence, noise, background sounds, and reversed speech |

The datasets allow us to study how hallucination behavior changes under **noise, domain shift, and adversarial conditions**.

---

##  Annotation Scheme

Each audio-transcript pair was manually assigned one of three labels:

### No Error
The transcript accurately represents the spoken audio.

### Non-Hallucination Error
The transcript contains ordinary ASR mistakes, such as:

- Misheard words
- Minor insertions or deletions
- Spelling errors
- Partial recognition failures

but remains grounded in the actual audio.

### Hallucination Error
The transcript contains fabricated or unsupported content that is not grounded in the audio.

For modeling, the labels are binarized into:
